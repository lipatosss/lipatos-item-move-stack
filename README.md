# LipatoS — Перемещение стопок предметов

Модуль для Foundry VTT. Репозиторий подготовлен к публикации исходного кода и релизов.

## Публикация

Загрузите исходный ZIP модуля в корень репозитория под именем `lipatos-item-move-stack.zip`.
GitHub Actions автоматически:
1. Распакует исходники в корень репозитория.
2. Обновит поля `manifest` и `download` в `module.json` для этого репозитория.
3. Соберёт установочный ZIP с `module.json` в корне архива.
4. Создаст или обновит релиз с тегом версии из `module.json`.

После публикации манифест: https://raw.githubusercontent.com/lipatosss/lipatos-item-move-stack/main/module.json

Установочный ZIP: https://github.com/lipatosss/lipatos-item-move-stack/releases/latest/download/lipatos-item-move-stack.zip

> Пока оригинальный ZIP не загружен, готового модуля и релиза здесь нет.
